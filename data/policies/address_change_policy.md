# Address Change Rules

An address-change request may be auto-processed when a valid policy number
is identified and the customer states a complete new address (street, city,
postal code).

If only a partial address is given (e.g. city but no street), the request
should be escalated for a manual follow-up rather than auto-applying a
partial address.

Address changes never require supervisor approval regardless of timing,
since they do not affect billing.
